# Credits

## Đảo Đèn Lồng (Lantern Island) — Phase 2 ("Ba Hòn Đảo")

- **Game Concept & Design**: Dao Den Long Phase 1 & Phase 2 specifications (Mây, Ông Đăng, Great Lanterns, Ink Shades, Drifters *Gió Lạc*, Wind Charms *Bùa Gió*, and the Lantern Moth companion *Bướm Đèn*).
- **3D Rendering**: Built with [Three.js](https://threejs.org/) (MIT License) using procedural primitive geometries only — no external 3D models or textures.
- **Bundler & Dev Server**: [Vite](https://vite.dev/) (MIT License).
- **Audio**: Procedural WebAudio API synthesis (ambient pentatonic night loop and gameplay SFX) — no external audio files.
