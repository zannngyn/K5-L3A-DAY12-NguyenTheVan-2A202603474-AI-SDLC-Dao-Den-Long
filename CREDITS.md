# Credits

## Đảo Đèn Lồng (Lantern Island) — v1.0.0 ("Bình Minh")

- **Game Concept & Design**: Đảo Đèn Lồng Phase 1–4 specifications (Mây, Ông Đăng, Great Lanterns *Đại Đăng*, Ink Shades *Bóng Mực*, Drifters *Gió Lạc*, Wind Charms *Bùa Gió*, and the Lantern Moth companion *Bướm Đèn*).
- **3D Rendering**: Built with [Three.js](https://threejs.org/) (MIT License) using procedural primitive geometries and `InstancedMesh` batching — no external 3D models or textures.
- **Bundler & Dev Server**: [Vite](https://vite.dev/) (MIT License), TypeScript, and [Vitest](https://vitest.dev/) (MIT License).
- **Audio**: Procedural WebAudio API synthesis (ambient D-minor pentatonic night loop and all gameplay SFX) — no external audio files.
- **UI & Accessibility**: Custom HTML/CSS HUD and overlays with Vietnamese typography, colorblind palette mode, reduced motion mode, large text scaling, key rebinding, and ARIA live-region captions.
- **AI Development Tools**: Built with AI-assisted coding and verification workflows (Anthropic Claude / Google Gemini coding agents) under human specification, review, and automated contract verification.
